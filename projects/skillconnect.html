SkillConnect Nepal

A full-stack local service marketplace connecting customers with verified professionals — from provider discovery to booking, payment, and review.

Overview

SkillConnect Nepal is a two-sided marketplace built to connect customers with verified local service providers — electricians, tutors, cleaners, and similar trades — in a straightforward, trustworthy booking flow.

Role

Role: Full-stack developer — backend architecture, API design, frontend build, and deployment

Problem

Finding a reliable local service provider in Nepal is largely word-of-mouth, with no easy way to compare verified providers, book a time, or pay online.

Solution

A Django REST Framework backend organized into 12 focused apps handles auth, provider profiles, bookings, payments, and reviews. A React front end (styled with Tailwind CSS) consumes that API, with JWT authentication and Django Channels powering real-time booking status updates over WebSockets.

My responsibilities

  • Architected the Django REST API across 12 apps, including permission classes for provider and customer roles.
  • Built the React frontend and connected it to the API, including the end-to-end booking flow from discovery to confirmation.
  • Integrated Cloudinary for media storage and eSewa/Khalti for local payment processing.
  • Set up the deployment stack with Docker, Nginx, and Daphne (for WebSocket support), plus PostgreSQL as the production database.
  • Designed a "verified docket" visual system for the product — a rhododendron-red stamp motif that marks approved providers.

Outcomes

  • A working full-stack marketplace with real-time booking status, live on GitHub with a complete local development setup.
  • A functioning admin panel for reviewing and approving provider applications.

Features

  • Verified-provider discovery and search
  • Real-time booking status via WebSockets
  • eSewa / Khalti payment integration
  • Admin panel for provider verification

Technologies

Django REST Framework React.js Tailwind CSS PostgreSQL Django Channels JWT Docker Nginx

Challenges

Setting up and debugging the full local development stack — Django, React, PostgreSQL, and Docker running together on Windows — took real trial and error before everything ran smoothly.

Lessons

Structuring a Django project into focused apps with clear permission boundaries made the API far easier to reason about as the project grew, and gave me a much better sense of how production backends are organized.
